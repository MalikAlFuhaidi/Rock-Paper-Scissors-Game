# Rock Paper Scissors Game (C++)

A simple console-based **Rock Paper Scissors** game developed in **C++** as part of my programming learning journey.

The player competes against the computer through multiple rounds. The computer generates random moves, and the game keeps track of the score before announcing the final winner.

## 🚀 Features

- Play between **1 and 10 rounds**
- Random computer choices
- Automatic winner detection for each round
- Final game statistics
- Console color changes based on the result
- Play again without restarting the application

## 🛠️ Technologies Used

- Visual Studio
- Console Application
